# Optional architecture report

materially helps review. Its offline, accessibility and rendering guidance owns
the presentation; this file adds only the architecture content contract.

expected benefit, migration risk, evidence and confidence. A before/after diagram
should show a real structural difference. Finish with the strongest supported
recommendation and any decision needed before implementation.
