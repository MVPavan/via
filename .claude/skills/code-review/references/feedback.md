# Incoming feedback

Read all findings, then assess dependencies between them. Verify each against the
code, governing requirement and available checks before implementing or dismissing
it. Preserve the review's wording where a durable fix loop needs traceability.

Each item ends with a visible disposition: fixed with evidence, answered with
evidence, awaiting a material clarification, or explicitly deferred with authority
and a revisit condition. A reviewer cannot expand scope or override an approved
decision. Surface such conflicts rather than silently adopting them.

Handle independent clear items while questions remain on others. Group related
fixes when they share a cause or verification; do not force one dispatch per item.
Disagreement is appropriate when grounded in evidence. Correct your own earlier
assessment when new evidence changes it.

Apply the same prompt adjudication inside and outside execution loops. After a fix,
verify the original failure and affected behavior; independent re-review depends
on the task's review requirement and risk. Analysis-only feedback requests receive
a disposition report without edits.
