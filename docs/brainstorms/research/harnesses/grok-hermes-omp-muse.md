## Grok Build CLI

- **Identity and install:** SpaceXAI calls the product Grok Build; the CLI executable is `grok`. Install with `curl -fsSL https://x.ai/cli/install.sh | bash` or `npm install -g @xai-official/grok`. Current vendor changelog lists **1.0.40, Sep 20, 2026**; the public source repository is Apache-2.0. [README](https://github.com/xai-org/grok-build), [changelog](https://x.ai/build/changelog)
- **Tier and access:** Tier 1: it is xAI’s coding harness for Grok models. It also supports custom OpenAI-compatible model endpoints. Sign-in is available for SuperGrok and X Premium Plus subscribers; API-key auth is documented for CI. [Custom models and auth](https://github.com/xai-org/grok-build/blob/main/crates/codegen/xai-grok-pager/docs/user-guide/11-custom-models.md), [xAI launch announcement](https://x.ai/news/grok-build-cli), [headless auth](https://docs.x.ai/build/cli/headless-scripting)
- **Headless behavior:** `grok -p "..."` runs one prompt. Output supports `plain`, `json`, `streaming-json`, and `streaming-messages-json`. JSON includes session ID and, when reported, tokens, per-model usage and cost. Cost may be absent or partial; absence does not mean zero. Exit codes are 0 success, 1 runtime/auth/network error, 130 SIGINT, 143 SIGTERM. Use `-m` for model, `--resume ID`/`--continue` to continue, `--prompt-file` for file input, `--yolo`/`--always-approve` for unattended tool execution, and sandbox/permission flags for access policy. Headless mode does not consume piped stdin. No headless effort flag was confirmed in the cited CLI docs. [Headless docs](https://github.com/xai-org/grok-build/blob/main/crates/codegen/xai-grok-pager/docs/user-guide/14-headless-mode.md), [permissions](https://docs.x.ai/build/features/permissions)
- **Other surfaces and ACP:** Native ACP is launched as `grok agent stdio` (registry launch is given in the question). Vendor docs describe sessions, load/resume, prompts, streamed replies, tool updates, reasoning and permission prompts. It also offers a WebSocket server via `grok agent serve`; docs show ACP/SDK integration but no standalone public SDK was confirmed. MCP client support is documented; MCP server mode is UNVERIFIED. The vendor does not state an ACP maturity tier. **Current ACP bugs: UNVERIFIED.** [Agent mode docs](https://github.com/xai-org/grok-build/blob/main/crates/codegen/xai-grok-pager/docs/user-guide/15-agent-mode.md), [MCP docs](https://docs.x.ai/build/features/mcp-servers)
- **Activity and VIA:** 27.1k GitHub stars; changelog shows frequent releases, latest 1.0.40 on Sep 20. VIA verdict: **v0**, because it has a structured one-shot result and explicit exit codes; add ACP when VIA needs live steering or cancellation. [Repository](https://github.com/xai-org/grok-build), [changelog](https://x.ai/build/changelog)

## Hermes Agent

- **Identity and install:** Hermes Agent is Nous Research’s open-source agent; executable `hermes`. Install with `curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash`, or use the Windows installer / PyPI package. MIT license. Latest GitHub release observed: **0.21.5, Sep 24, 2026**. [Repository and install](https://github.com/NousResearch/hermes-agent), [releases](https://github.com/NousResearch/hermes-agent/releases), [PyPI](https://pypi.org/project/hermes-agent/)
- **Tier and access:** Tier 2. Providers include Nous Portal, OpenRouter, OpenAI/Codex, Anthropic, Gemini, xAI, Copilot, local engines and custom endpoints. It supports Nous Portal subscription OAuth and ChatGPT/Codex device-code OAuth; the docs say Codex plan-quota semantics are not documented. Claude OAuth requires **Claude Max plus purchased extra-usage credits**; Claude Pro does not work through that path. [Provider docs](https://github.com/NousResearch/hermes-agent/blob/main/website/docs/integrations/providers.md)
- **Headless behavior:** `hermes chat --oneshot -q "..."` or `hermes chat -q "..." --format stream-json` runs non-interactively; structured output includes session ID, final text, token counts and exit code. `--usage-file` writes a JSON usage report. `--resume ID` / `--continue` continue sessions; `--provider`, `--model` and `--reasoning-effort` select inference. `--yolo` skips approval prompts; a dedicated general OS sandbox flag was not confirmed. Query-file/stdin input is supported. Non-interactive exit codes include 0 success, 1 failed/partial/budget/init failure, and 130 interrupted. [CLI reference](https://github.com/NousResearch/hermes-agent/blob/main/website/docs/reference/cli-commands.md), [sessions](https://github.com/NousResearch/hermes-agent/blob/main/website/docs/user-guide/sessions.md)
- **Other surfaces and ACP:** Hermes has an API server (`hermes serve`), plus `hermes mcp serve` for a stdio MCP server. That MCP server exposes messaging/conversation tools, not the coding-agent toolset. It also connects to external MCP servers. ACP is native via `hermes acp` / `hermes-acp`; docs describe list/load/resume/fork, prompt, cancel, streaming, and permission handling. Per the supplied registry check there is no ACP registry entry. No stable/preview label is published; maturity label is **UNVERIFIED**. [CLI reference](https://github.com/NousResearch/hermes-agent/blob/main/website/docs/reference/cli-commands.md), [ACP docs](https://github.com/NousResearch/hermes-agent/blob/main/website/docs/user-guide/features/acp.md), [MCP docs](https://github.com/NousResearch/hermes-agent/blob/main/website/docs/user-guide/features/mcp.md)
- **Activity and VIA:** 248.6k GitHub stars; frequent release activity, including a release on the date of this survey. VIA verdict: **v0**, because stream-json and usage-file give useful structured results immediately; ACP is a good lifecycle route for steer/cancel. [Repository](https://github.com/NousResearch/hermes-agent), [releases](https://github.com/NousResearch/hermes-agent/releases)

## `omp` / Oh My Pi

- **Identity and install:** Herdr’s docs use `omp` as an agent kind; its source identifies the product as **Oh My Pi**, built by Stencil Labs and forked from Pi. Executable: `omp`. Install from source with the repo’s Bun setup, or use the release binaries/npm distribution. MIT license. Latest release observed: **18.2.11, Sep 23, 2026**. [Herdr agent docs](https://github.com/herdrdev/herdr/blob/master/docs/next/website/src/content/docs/agents.mdx), [Oh My Pi repository](https://github.com/can1357/oh-my-pi), [releases](https://github.com/can1357/oh-my-pi/releases)
- **Tier and access:** Tier 2. Its docs list 60+ providers, including Anthropic, OpenAI/Codex, Gemini, xAI, OpenRouter, local inference and gateways. It supports OAuth/account login and subscription routes, including OpenAI Codex and SuperGrok. [Provider docs](https://github.com/can1357/oh-my-pi/blob/main/docs/providers.md), [README provider list](https://github.com/can1357/oh-my-pi)
- **Headless behavior:** `omp -p "..."` prints a one-shot result; `--mode json` provides a JSON event stream. CLI flags cover `--model`, `--thinking`, `--resume`/`--continue`, tools, and approval modes. The docs do not establish a stable one-shot result envelope equivalent to VIA’s target schema; use RPC if exact lifecycle/usage metadata is required. [CLI implementation](https://github.com/can1357/oh-my-pi/blob/main/packages/coding-agent/src/cli/args.ts), [README](https://github.com/can1357/oh-my-pi)
- **Other surfaces and ACP:** OMP offers an in-process Node SDK, newline-delimited JSON RPC (`omp --mode rpc`), and native ACP (`omp acp`). RPC documents prompt, model/effort changes, abort, session state and streaming events. ACP supports editor-routed tools and permission requests. The supplied check found no ACP registry entry. No official stable/preview maturity label found; maturity label is **UNVERIFIED**. MCP client operation is documented; MCP server mode is UNVERIFIED. [RPC docs](https://github.com/can1357/oh-my-pi/blob/main/docs/rpc.md), [README](https://github.com/can1357/oh-my-pi)
- **Activity and VIA:** 33.1k GitHub stars; releases are frequent, with latest observed Sep 23. VIA verdict: **v1**; use RPC for lifecycle control, steering and cancellation, and retain `-p` for simple one-shot tasks. [Repository](https://github.com/can1357/oh-my-pi), [releases](https://github.com/can1357/oh-my-pi/releases)
