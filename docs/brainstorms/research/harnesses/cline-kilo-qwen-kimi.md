### Cline CLI

- **Identity and install:** Cline’s open-source coding agent is maintained at [cline/cline](https://github.com/cline/cline); the CLI package is `cline`, installed with `npm install -g cline`, and its executable is `cline`. npm showed **3.0.65**, published Sep 24. The repository is Apache-2.0. [npm package](https://www.npmjs.com/package/cline), [repository and license](https://github.com/cline/cline)
- **Tier and access:** **Tier 2** because Cline documents many independent providers: Anthropic, OpenAI, Google, OpenRouter, Bedrock, Vertex, local runtimes, and OpenAI-compatible APIs. Its ACP guide also lists Cline, ClinePass, and ChatGPT-subscription sign-in. That confirms subscription sign-in is available, though the guide does not establish support for every provider’s consumer subscription. [Provider list](https://github.com/cline/cline#cline), [ACP sign-in](https://github.com/cline/cline/blob/main/docs/usage/acp.mdx)
- **Headless behavior:** `cline "task"` runs one task; `--json` emits newline-delimited JSON. Flags include `--model`, `--provider`, `--thinking`, `--plan`, `--auto-approve`, and `--yolo`. `--data-dir` enables sandbox mode. `--id` is documented for existing sessions, but an open Aug. 13 report says `--json --id ID prompt` rejects the prompt in versions 3.0.53/3.0.54. Treat headless resume as **UNVERIFIED pending confirmation against 3.0.65**. Session ID/usage/cost fields in the JSON result and process exit-code contract: **UNVERIFIED**. [CLI options and JSON schema](https://github.com/cline/cline/blob/main/apps/cli/README.md), [reported resume issue](https://github.com/cline/cline/issues/13239)
- **Other surfaces and ACP:** Cline has a TypeScript SDK (`@cline/sdk`), a local Hub daemon, and MCP-client support. It speaks native ACP via `cline --acp`; docs describe session loading, permission prompts, model/provider selection, and plan/act modes. [SDK](https://github.com/cline/cline/tree/main/sdk), [ACP docs](https://github.com/cline/cline/blob/main/docs/usage/acp.mdx)
- **Activity and VIA:** 69.2k stars; npm showed a release within minutes of its page being checked. [GitHub repository](https://github.com/cline/cline), [npm package](https://www.npmjs.com/package/cline). **VIA: v1 via ACP** for persisted session controls; keep the `--json` one-shot route as a fallback while testing current headless resume and structured result fields.

### Kilo Code CLI

- **Identity and install:** Product is Kilo Code, vendor Kilo-Org, repo [Kilo-Org/kilocode](https://github.com/Kilo-Org/kilocode), MIT license. Install `@kilocode/cli` with npm; executable is `kilo`. Kilo explicitly says its CLI is an **OpenCode fork**. [README](https://github.com/Kilo-Org/kilocode), [npm package](https://www.npmjs.com/package/%40kilocode/cli)
- **Version discrepancy:** GitHub’s releases page shows CLI release **7.7.6 on Sep 21**; npm’s page showed **7.7.5**; the supplied ACP registry entry says **7.7.9**. Those sources disagree, so the exact latest CLI version on Sep 24 is **UNVERIFIED**. [GitHub releases](https://github.com/Kilo-Org/kilocode/releases), [npm package](https://www.npmjs.com/package/%40kilocode/cli), [ACP registry](https://github.com/agentclientprotocol/registry)
- **Tier and access:** **Tier 2**: it routes among hundreds of provider/model choices. Users can connect provider keys and can sign in with a ChatGPT Plus/Pro subscription using OAuth for Codex models. Its own Gateway/Kilo credits are another option. [Providers and models](https://kilo.ai/docs/gateway/models-and-providers), [ChatGPT subscription](https://kilo.ai/docs/ai-providers/openai-chatgpt-plus-pro)
- **Headless behavior:** `kilo run --auto "task"` runs unattended; `--format json` emits raw JSON events. Model selection uses `--model provider/model`; resume supports `--continue` and `--session ID`. The CLI docs say `--continue` cannot be combined with autonomous mode or a prompt, which obstructs a single-command resume-and-steer loop. Exit codes are documented (`0`, `124`, `1`). Usage/cost can be inspected with `kilo stats`; per-run usage fields are **UNVERIFIED**. Permission rules can allow/ask/deny tools; in noninteractive non-auto runs, approval requests are rejected. [CLI guide](https://kilo.ai/docs/code-with-ai/platforms/cli), [CLI reference](https://kilo.ai/docs/code-with-ai/platforms/cli-reference)
- **Other surfaces and ACP:** Native `kilo acp`, `kilo serve` headless server, session/export commands, and MCP configuration are documented. The ACP registry supplies `kilo acp` as the launch command. Specific ACP load/resume, cancel, usage, and steering capabilities and a formal maturity label are **UNVERIFIED** from the sources checked. [CLI docs](https://kilo.ai/docs/code-with-ai/platforms/cli), [ACP registry](https://github.com/agentclientprotocol/registry)
- **Activity and VIA:** 27.4k stars and a Sep. 21 CLI release indicate active development. [Repository](https://github.com/Kilo-Org/kilocode), [releases](https://github.com/Kilo-Org/kilocode/releases). **VIA: v1 via ACP**, subject to a protocol probe; use the CLI path if JSON-event stability and resume-with-prompt are verified.

### Qwen Code

[Overview/install](https://qwenlm.github.io/qwen-code-docs/en/users/overview), [repository](https://github.com/QwenLM/qwen-code)
- **Fork claim:** Confirmed: it began from Google Gemini CLI v0.8.2, but the project says it stopped syncing with upstream at Qwen Code v0.1 and developed independently. [Acknowledgment](https://github.com/QwenLM/qwen-code#acknowledgments)
- **Version and activity:** Latest stable release shown was **0.24.4**; **0.24.5-preview.0** was also listed. Release page shows 0.24.4 among releases but did not expose its date in the inspected excerpt; exact stable date is **UNVERIFIED**. The repo page showed 28.1k stars; the package docs state daily nightlies and weekly previews. [Releases](https://github.com/QwenLM/qwen-code/releases), [release process](https://github.com/QwenLM/qwen-code/blob/main/docs/developers/development/npm.md), [repository](https://github.com/QwenLM/qwen-code)
- **Tier and access:** Classified **Tier 1** as a model-provider-owned harness with deep Qwen integrations, though it now supports many providers: Alibaba ModelStudio, OpenAI-compatible endpoints, Anthropic, Gemini, Vertex AI, and named third parties. Alibaba ModelStudio offers coding/token plans and API keys; other providers require their own credentials. Qwen OAuth free access was discontinued Apr. 15, 2026. [Authentication](https://qwenlm.github.io/qwen-code-docs/en/users/configuration/auth/), [provider configuration](https://qwenlm.github.io/qwen-code-docs/en/users/configuration/model-providers/)
- **Headless behavior:** `qwen -p ...` supports text, `--output-format json`, and `stream-json`; docs describe session ID/model in session-start output, execution summary, exit codes, and `--continue` / `--resume ID`. [Headless docs](https://qwenlm.github.io/qwen-code-docs/en/users/features/headless/)
- **Other surfaces and ACP:** Native `qwen --acp`; also `qwen serve` (HTTP/SSE daemon), TypeScript SDK, and MCP servers as tool integrations. The docs describe ACP session load/resume/cancel; registry launch supplied is `npx @google/gemini-cli --acp`? **UNVERIFIED conflict:** the registry details supplied for Qwen say `npx @qwen-code/qwen-code --acp --experimental-skills`; use that exact command pending direct entry verification. The daemon docs warn that ACP sessions do not consult `--max-wall-time` / `--max-tool-calls` settings. [Architecture](https://qwenlm.github.io/qwen-code-docs/en/developers/architecture/), [daemon API](https://qwenlm.github.io/qwen-code-docs/en/developers/daemon-rest-api-reference/), [budget caveat](https://qwenlm.github.io/qwen-code-docs/en/users/features/headless/)

### Kimi CLI (Moonshot, legacy)

- **Identity and install:** This is the legacy Python Kimi CLI, repo [MoonshotAI/kimi-cli](https://github.com/MoonshotAI/kimi-cli), Apache-2.0. Historically installed from PyPI and invoked as `kimi`. Version **1.52.0**, released Sep. 22, is the last version; the repository was archived Sep. 23 and the release redirects the `kimi` entry point to Kimi Code’s installer. [Release](https://github.com/MoonshotAI/kimi-cli/releases), [archive notice](https://github.com/MoonshotAI/kimi-cli/issues/2661)
- **Tier and access:** **Tier 1** provider-owned, while supporting Kimi, OpenAI, Anthropic, Gemini, Vertex AI, and compatible services. `kimi login` supports Kimi account OAuth; other providers are configured with API keys/credentials. The docs do not confirm using consumer Claude or ChatGPT subscriptions. [Provider docs](https://moonshotai.github.io/kimi-cli/en/configuration/providers.html), [login docs](https://moonshotai.github.io/kimi-cli/en/reference/kimi-command.html)
- **Headless behavior:** `kimi --print -p ...` exits after the task; `--output-format stream-json` emits JSONL and stream-JSON input supports multiple messages. The docs specify exit codes 0, 1, and 75. Resume supports `--continue` or `--resume ID`; stdout prints a resume hint on exit. Effort/model flags, result usage/cost contract, and non-TTY blockers: **UNVERIFIED** here. [Print mode](https://moonshotai.github.io/kimi-cli/en/customization/print-mode.html), [sessions](https://moonshotai.github.io/kimi-cli/en/guides/sessions.html)
- **Other surfaces and ACP:** Native `kimi acp` and `kimi mcp` configuration management; a separate Moonshot Agent SDK exists in Go, Node, and Python. ACP session resume was described as experimental in the changelog; with the repository archived, assume no future fixes. [ACP command](https://moonshotai.github.io/kimi-cli/en/reference/kimi-acp.html), [changelog](https://github.com/MoonshotAI/kimi-cli/blob/main/CHANGELOG.md), [Agent SDK](https://github.com/MoonshotAI/kimi-agent-sdk)
- **Activity and VIA:** 11.4k stars, but explicitly archived with no further releases, fixes, or security updates. The active successor is **Kimi Code CLI**, a separate product/repository; do not treat it as version 1.52.0. [Legacy repository](https://github.com/MoonshotAI/kimi-cli), [migration notice](https://github.com/MoonshotAI/kimi-cli/issues/2661). **VIA: never for legacy; later for the Kimi Code successor**, after its CLI/ACP contracts are surveyed independently.
