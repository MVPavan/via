## Choices where the design was open

- **`AnchorOwner.phase` is `Option<AnchorPhase>`.** `None` means the stored
  phase is unreadable. `s1_f10_failed_host_reconciliation_refuses_admission`
  tampers the phase and expects Host reconciliation, not the owners page, to
  name the failure; a required phase broke that. S4 should treat `None`
  conservatively.
- **New Store reads.** `keyed_operation` exposes a close still in progress,
  and `session_close_result` implements §4 step 3. `operation()` reports a
  resultless close row with `result: null`, so a resume that reuses the key
  fails the identity check.
- **`StoreError::Refused`** is added for Store-defined refusals: `resume` on
  closing, and `Closing` or `Closed` on a closed session. `commit_closed`
  returns `ClosedOutcome::Unfinished` for the unfinished-turn refusal.
- **Where the read seams sit.** `store.read.dispatch` sits at the worker for
  `Predecessors`, `QueuedTurn` and `NextSeq` (the head's lock read), and
  `store.read.queued_turn` only at `QueuedTurn`. Both fire for any caller of
  those reads. `store.sqlite.corrupt` fires on reads only.
  `store.writer.lost` drops any dequeued request unserved.
- **An order already set when `execute` starts** returns
  `Stopped { launched: false, cleanup: None }` without touching Host (no
  anchor intent). An order that arrives during acquisition is caught at
  Host's gate, with the acquisition's own absence evidence.
- **F21.** The confirmed-exit wait after an unterminated line is bounded by
  `min(turn deadline, now + 3 s)`, and anything but a confirmed exit is
  `TransportLost`. Plain EOF keeps its earlier semantics.
- **A decoded terminal whose finalization outlives the wall deadline**
  returns `Ok` with cleanup from Host's force close. Its `exit` is
  `{code: None, signal: None}` when no exit was confirmed. The disposition
  is S2's.
- **Journal-write latch evidence beyond the cause.**
  `RouteFailure.journal_uncertain`, `FakeRouteResult.journal_uncertain` and
  `FakeTerminalEvidence.journal_uncertain` carry an uncertain absence-proof
  commit from a close, which must latch (row 12). An uncertain
  `reprobe_held` commit is returned as `HostError::Journal { Absence,
  uncertain: true }`.
- **Release builds contain no point names.** Store commit seams are a macro
  that expands to nothing in release builds. The release check arms 41
  points and finds none of 45 markers.
- **Extra test-only seams**, used to reach races deterministically:
  `host.early_stop.snapshot` (after the snapshot) and
  `host.anchor.arm_received` (before the vendor spawn). Every Host seam is
  compiled only with `test-failpoints`. The anchor takes the controller's
  directory and token from its bootstrap file (0600, deleted on read).
