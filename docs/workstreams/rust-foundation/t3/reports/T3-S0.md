Placement choices:

- `slot_for`, `hold` and the `receipted`/`request_start`/`retire` helpers
  stay in `engine.rs`. They are shared by receipts, recovery and dispatch,
  and a child module can reach its parent's private items, so this needs no
  visibility change.
- `receipt_failed` and `receipt_reply` go with the receipts, their only
  callers.
- `Joins` and `Client` stay in `server.rs`. `serve` builds both, and the
  children read their private fields as descendants. Moving them would have
  needed `pub(super)` on the structs and on every field.

## Non-move edits

Visibility (each is `pub(super)`; nothing became `pub` or `pub(crate)`):

- `engine/latch.rs`: `latch_finalized` (used by `engine/tests.rs`),
  `read_retries_until` and `read_cutoff` (used by `engine/drive.rs`).
- `engine/slots.rs`: `RecoveredSlots::hold` and `hold_unidentified` (used by
  `engine/recovery.rs`), and `RecoveredGroup`. `hold` returns it, and
  without the change `recovery.rs` fails with E0603 (`type RecoveredGroup
  is private`) and the `private_interfaces` lint fires.
- `server/dispatch.rs`: `handle_client`; `server/shutdown.rs`:
  `final_shutdown` (both called by `serve`).
- `latch` and `latch_held` keep their `pub(super)` text. In the new file it
  means `engine` rather than the crate root, which is narrower. Nothing
  outside `engine` calls them.

Cursor move (design §13 [r1.21]):

- `Recovered` gains `cursor: Option<String>` with a doc comment.
  `RecoveredSlots` gains `pub(super) fn save_cursor`, which stores it under
  the existing mutex.
- `reconcile` (`engine/recovery.rs`) calls
  `self.recovered.save_cursor(after.clone())` in the deadline branch,
  immediately before `unproven_anchors_up_to(after, pool)`. Nothing reads
  the cursor yet (the re-probe loop that will is a later slice), so the
  only runtime effect is one clone and one uncontended lock on the
  startup-deadline path. rustc raises no `dead_code` warning for a field
  that is written but never read, so no `expect` attribute is needed.

Module wiring and imports:

- `engine.rs`: `mod latch; mod read; mod receipt; mod slots;` added in
  alphabetical order. `recovery::RecoveredSlots` → `slots::RecoveredSlots`
  (field type and initializer). Imports trimmed to what remains, and
  `SESSION_QUEUE_LIMIT` dropped from the `queue` import.
- `engine/recovery.rs`: removed the now-unused
  `use std::sync::{Arc, Mutex, PoisonError};`. Its test module drops
  `use std::sync::Arc;` and `RecoveredSlots` from its `super` import.
- `server.rs`: `mod dispatch; mod shutdown;`,
  `use dispatch::handle_client; use shutdown::final_shutdown;`, and
  imports trimmed.
- Each new file has a short `//!` module doc (matching the sibling
  modules) and its own `use` lines. Each moved test module keeps
  `#[cfg(test)] mod tests { use super::*; … }`, or an explicit
  `use super::RecoveredSlots;` in `slots.rs`.
