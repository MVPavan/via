## Method

- Failure-first, per `../w1/common.md` and coding-style §10. Before each
  behaviour change, write a regression that fails on the base for the stated
  reason; record the failing run. A test that passes on the base is a
  characterization test; label it so. A compile failure alone is not
  failure-first evidence for a behavioural test.
- No fixed sleep as an ordering assertion. Use the §10 seams and
  acknowledgements; a sleep may only create elapsed time.
- Where the design is ambiguous, choose the reading that keeps S3–S5
  possible, and record the choice in the report.
