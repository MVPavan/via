## Outcome

Split by responsibility, with no behaviour change:

- `crates/via-core/src/engine.rs` → `engine.rs` (the `Engine` struct,
  `open`, shared helpers), `engine/receipt.rs` (spawn, resume,
  `queue_turn`, steer), `engine/read.rs` (address, result, wait, events,
  logs) and `engine/latch.rs` (latch, force signal, read cutoff);
- `RecoveredSlots` and the reconciliation cursor move from
  `engine/recovery.rs` into `engine/slots.rs`. `reconcile` stores its
  cursor there at the deadline, which changes no behaviour;
- `crates/via-cli/src/server.rs` → `server.rs` (startup, serve loop),
  `server/dispatch.rs` (client loop, method dispatch, stop request,
  parsing) and `server/shutdown.rs` (final shutdown, joins).

## Rules

- Moves only. Function bodies, names, lock order and comments stay as they
  are. Allowed non-move edits are limited to module declarations, `use`
  lines, the narrowest visibility changes needed (`pub(super)` or
  `pub(crate)`; nothing becomes `pub`) and the cursor move above. List
  every non-move edit in the report.
- Keep each moved item's doc comment with it. Match the surrounding code
  style (`.repo-context/coding-style.md`).
- Touch no other file, except where a test module path must change; name
  any such file in the report.
- `git diff -M --stat` against the base should read as moves.
