### 3. New defects and slices

- **Blocker — follower ownership:** `Permit::split` promises transfer, `push_events` promises a new acquisition, and `EventSink::push` accepts only events. Define a charged event batch carrying its permit into the outbox; test the 1 MiB high-water at a full rescan. `docs/workstreams/rust-foundation/t4/design.md:1535`, `docs/workstreams/rust-foundation/t4/s6.md:53`.
- **Important — stale liveness:** `Armed` records that spawn happened. Host’s exit watcher can publish a confirmed exit without clearing that ledger phase, while the control remains upgradeable. Make `live_armed` exclude a confirmed exit and test status between exit evidence and control drop. `crates/via-host/src/host.rs:101`, `crates/via-host/src/host.rs:1319`.
- **Important — impossible boundary fixture:** S2 requires an existing absolute 4096-byte control-character `cwd`; the worktree filesystem reports `PATH_MAX=4096`, so that path cannot pass `metadata().is_dir()`. Use the longest valid created path for end-to-end testing and synthetic records for the full 4096-byte encoding bound. `docs/workstreams/rust-foundation/t4/s2.md:139`, `docs/workstreams/rust-foundation/t4/s2.md:176`.
