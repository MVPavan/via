2. **Important — Hygiene scanning misses JSON-escaped sensitive strings.**  
   [fixtures.rs:424](../../../../../crates/via-fake-agent/tests/fixtures.rs#L424) scans raw file text for paths, emails, and token prefixes. After JSON decoding, it checks only credential fields. Thus Unicode-escaped home paths, email separators, or token prefixes pass—including inside encoded emit messages. Escaped forward slashes provide another path bypass.
   
   The self-test at [fixtures.rs:453](../../../../../crates/via-fake-agent/tests/fixtures.rs#L453) detects its supplied examples, but does not cover these representations.
   
   **Smallest fix:** apply the string-pattern checks to decoded string leaves, recursively including strings containing JSON; add escaped variants of every required pattern.

3. **Important — Credential-placeholder recognition accepts values containing additional data.**

   **Smallest fix:** accept a small set of complete placeholder values, rather than prefixes or substrings; test appended and embedded data.

9. **Important — EOF, forbidden extra input, and cleanup provenance remain unpinned.**  
   The relevant replay limitation is real: [replay.rs:223](../../../../../crates/via-fake-agent/src/replay.rs#L223) reads only expect steps and exits after the final step.    **Smallest fix:** coordinate EOF/strict-input support or independent transport assertions, and add cleanup-evidence assertions to the driver. These should remain explicitly unverified until implemented.

11. **Important — c10 models a different action from its recording and misreads “running.”**
